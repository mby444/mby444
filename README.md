### 🚀 Featured Projects & Research Documentation

#### 1. 🌋 Mt. Merapi Volcano Deformation EWS & ML Pipeline
> **Status:** Active Research (MBKM Software Engineering & SINTA Journal Publication)  
> **Tech Stack:** `Python`, `Scikit-Learn`, `XGBoost`, `Pandas`, `SMOTE`

A modular 5-stage Machine Learning pipeline engineered to classify volcanic deformation signals at Mount Merapi using spatial Electronic Distance Measurement (EDM) datasets (2007–2013) across 6 monitoring sectors (`BAB`, `DEL`, `JRA`, `KAL`, `MRI`, `SEL`).
- **Key Highlights:** Implemented 7-day sliding window feature engineering, signed slope extraction, `RobustScaler` normalization to handle volcanic outliers, and decision threshold tuning (30%) to maximize minority class recall for real-time Early Warning System (EWS) scenarios.
